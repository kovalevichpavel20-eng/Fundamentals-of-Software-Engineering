# Fundamentals-of-Software-Engineering


В данной практической работе исследуются базовые и продвинутые возможности языка Python при работе с различными типами данных, механизмами их приведения и базовыми операциями ввода-вывода. В теоретической части анализируются особенности динамической типизации, а также приоритеты выполнения арифметических операций, таких как целочисленное деление и деление с плавающей точкой. Практическая часть включает в себя детальный анализ встроенной функции int() и её ограничений при конвертации некорректных строковых литералов или сверхбольших вещественных чисел. Отдельное внимание уделено управлению памятью и оценке физического размера объектов в байтах и мегабайтах с помощью системного модуля sys.getsizeof().
Важной частью работы является написание программ под жесткими функциональными ограничениями — без использования нелинейных конструкций, таких как ветвления if-else, циклы или встроенные функции выбора. С помощью альтернативных подходов (логического индексирования списков и бинарной логики) реализованы алгоритмы поиска наибольшего из двух чисел, проверки кратности чисел нацело, а также математического определения цвета клеток шахматной доски по их координатам. Кроме того, разработана программа для симуляции электронных часов, переводящая секунды в строгий формат времени h:mm:ss с помощью целочисленной арифметики и форматирования строк. Продвинутый уровень работы включает в себя создание скриптов для автоматизации чтения и обработки данных из внешних файлов. Реализованы алгоритмы для сквозного расчета расстояний между локациями на карте с учетом масштаба, а также формульный расчет метеорологического индекса охлаждения ветром (Wind Chill) с последующим экспортом агрегированных результатов в итоговые текстовые отчеты.
Инструкция по запуску
1. Подготовка среды: Убедитесь, что на компьютере установлен интерпретатор Python версии 3.x. Проверить это можно, введя команду python --version в терминале.
2. Создание файлов: Скопируйте программный код нужного задания в текстовый файл и сохраните его с расширением .py (например, main.py).
3. Размещение данных (для блока B): Если запускается программа для расчета расстояний или индекса охлаждения ветром, скачайте необходимые файлы с исходными данными (например, inmap0.dat или 1.WCData.txt) и положите их в ту же самую папку, где находится файл с кодом.
4. Запуск программы: Откройте командную строку или терминал, перейдите в каталог с вашей программой при помощи команды cd путь_к_папке и выполните команду:bash
python main.py
Используйте код с осторожностью.
5. Ввод параметров: Если программа является интерактивной, введите запрашиваемые числовые значения или координаты в консоль поочередно, нажимая клавишу Enter после каждого ввода, и ознакомьтесь с выведенным результатом.
